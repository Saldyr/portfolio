# Portfolio Romain Cartia

Portfolio personnel présentant mon parcours et mes projets, avec un formulaire de contact. Développé avec Next.js et TypeScript.

## Démarrer

```bash
npm install
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000).
